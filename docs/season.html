2026-27 season

Season forecasts

The committed model's probabilities for Premier League fixtures, computed from pre-kickoff information only: form, Elo, league position, squad value and the bookmaker's price. Each fixture shows the home, draw and away probabilities, the most likely scoreline from the Dixon–Coles grid, and the strongest signals behind the call.

Read before usingThese are model probabilities on pre-kickoff information, not betting advice. On the 2025-26 holdout the model's own log loss, 1.019, sat marginally behind the market's 1.016. The model is the one whose numbers appear across this site: trained on 2000-01 to 2022-23, blend and calibration tuned on 2023-25, never retrained since.

This page reads docs/data/upcoming.json, and that file has not been generated. It is produced by predict_upcoming.py from a fixtures-and-prices file that you supply.

What the file needs. One row per fixture with the fixture date, the two clubs, and the bookmaker's three match-odds prices as quoted (vig included). The columns use football-data.co.uk's names, so a fixtures export from that site can be saved as-is:

  • Date (dd/mm/yyyy), HomeTeam, AwayTeam
  • one price triple: B365H, B365D, B365A or AvgH, AvgD, AvgA
  • strongly recommended: the over/under 2.5 prices (B365>2.5, B365<2.5 or Avg>2.5, Avg<2.5). Without them the goal model starts from league-average expected goals and its 70% share of the blend drifts toward the middle
  • optional: Time (UK kickoff), closing prices

Where it comes from. football-data.co.uk, the same source as the 25 seasons the model was trained on. Club names must match that site's spelling (for example Nott'm Forest, Man United).

How to generate the forecasts.

# 1. save the fixtures file as
data/upcoming/2026-27.csv
# 2. score it with the committed model (the parity gate runs first)
python predict_upcoming.py
# 3. commit the outputs
git add docs/data/upcoming.json docs/data/upcoming.js

Fixtures that already have a result in data/2026-27.csv are scored from their pre-kickoff row and shown with the result, so the page doubles as a running scorecard.

How to read a forecast

The bar is the calibrated blend of the two models: 0.30 on the boosted-tree classifier and 0.70 on the Dixon–Coles goal model, then one temperature parameter of 1.04. The most likely scoreline comes from the goal model's scoreline matrix. The signals are the classifier's largest feature contributions toward its predicted class, in log-odds; the arrow says which club they favour.

A fixture is flagged early season when either club has fewer than 3 games this season. The model was only trained and scored on rows with more history than that, so its form features are incomplete there and the market prior carries more of the answer. Every forecast on this page is produced by predict_upcoming.py, which refuses to write anything unless the rebuilt features reproduce the published holdout predictions to within rounding.
