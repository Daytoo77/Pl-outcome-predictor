Premier League match-outcome model

Predicting football against the bookmaker's line

A home / draw / away classifier for Premier League fixtures, trained on 25 seasons using only what is knowable before kickoff. It starts from the vig-free market price and only tries to improve on it.

Results on seasons the model never trained on

Log loss is the score that matters: lower is better, and a flat one-third guess scores 1.099. The market column is the de-vigged consensus price, the hardest benchmark there is.

Held-out performance
SliceMatchesModel log lossMarket log lossAccuracyAlways home
Test, 2023-24 and 2024-25 699 0.946 0.949 56.1% 43.9%
Holdout, 2025-26 (scored once) 350 1.019 1.016 48.3% 42.0%

On the freshest slice the model finished 0.003 behind the closing line, a tie inside the noise. Draws are the hard class: no pre-kickoff feature correlates with a draw, so the model treats a well-calibrated draw probability as the deliverable rather than the hard label, and under argmax it called none of the 163 drawn test matches.
